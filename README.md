# Zeneth Theme

A clean, minimal VSCode theme with almost no borders for a distraction-free coding experience.

![Zeneth Theme Preview](https://img.shields.io/badge/VSCode-Theme-blue?style=flat-square)
![License](https://img.shields.io/badge/License-GPL--3.0--only-green?style=flat-square)
![Version](https://img.shields.io/badge/Version-1.0.0-orange?style=flat-square)

## Features

- **Minimal Design**: Clean aesthetic with minimal borders and visual clutter
- **Dark Theme**: Easy on the eyes for long coding sessions

## Installation

1. Open VSCode
2. Go to Extensions (Ctrl+Shift+X)
3. Search for "Zeneth Theme"
4. Click Install

### Alternative Installation

You can also install the theme directly from the marketplace:

```bash
code --install-extension Edanick.theme-zeneth
```

## Activation

1. Press `Ctrl+Shift+P` (or `Cmd+Shift+P` on Mac)
2. Type "Theme" and select "Preferences: Color Theme"
3. Choose "Zeneth" from the list
